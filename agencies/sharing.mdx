## Preview links

For a landing page, site or form, from its **Share** tab. They show the draft
before it goes live, so a client can approve it.

| | |
| --- | --- |
| Access code | Six digits, on by default |
| Expires | After 7 days, 30 days, or never |
| Links per item | Up to 25 |

## Template links

A frozen copy of a page, site, form or lead magnet that anyone with a ManyPI
account can add to their own workspace. Responses, leads, analytics and
domains never come along, and custom code stays switched off in the copy.
Creating one needs Sites **edit** and the `share_public` action. See also
[Share a form as a template](/forms/share-as-template).

## Lead share links

A live lead list, not a copy.

| | |
| --- | --- |
| Access | View, comment or edit (comment and edit need an account) |
| Fields | Hide the ones they shouldn't see |
| Download / import | Allow or not |

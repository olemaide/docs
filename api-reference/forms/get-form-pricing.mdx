---
title: "Get form pricing"
description: "An instant quote form's draft price book, the names its formulas can use, its pricing checks, and a quote for sample or given answers."
---

`GET /api/forms/{id}/pricing`, API key scope `read`. Also available as the `get_form_pricing` and `preview_form_quote` MCP tools.

Returns the draft's price lines and settings, the names formulas can use, each
option's values, the pricing problems that block publishing, whether the prices
are still unconfirmed examples, whether booking and deposits are on, and a
quote for sample answers. Booking and deposit details aren't returned.

| Parameter | In | Description |
|---|---|---|
| `id` | path | Form uuid, public id or key |
| `answers` | query | JSON object, question ref to answer, merged over the sample answers (optional) |
| `tier` | query | A package ref (optional) |

## Example

```bash
curl "https://app.manypi.com/api/forms/{id}/pricing?answers=%7B%22area%22%3A2000%7D" \
  -H "Authorization: Bearer $MANYPI_API_KEY"
```

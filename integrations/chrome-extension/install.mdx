ManyPI Email Finder is in the Chrome Web Store as
**ManyPI: Email Finder & Lead Extractor**. It needs Chrome 116 or newer, or
another Chromium browser such as Edge, Brave or Arc.

<Card title="Add to Chrome" icon="chrome" href="https://chromewebstore.google.com/detail/manypi-email-finder-lead/picghbcemlfoofheelmfghbmflpnclja" horizontal>
  Open the listing in the Chrome Web Store.
</Card>

<Steps>
  <Step title="Add it to Chrome">
    Open the [Chrome Web Store listing](https://chromewebstore.google.com/detail/manypi-email-finder-lead/picghbcemlfoofheelmfghbmflpnclja)
    and click **Add to Chrome**, then **Add extension**.
  </Step>
  <Step title="Pin it">
    Click the puzzle icon in the toolbar and pin ManyPI so it is one click away.
  </Step>
  <Step title="Open the side panel">
    Click the ManyPI icon. The panel opens next to the page you are on.
  </Step>
  <Step title="Sign in with ManyPI">
    Click **Sign in with ManyPI** and approve the connection. Leads you send
    go to the workspace and brand you work in.
  </Step>
</Steps>

Chrome keeps the extension up to date on its own.

## Installed the downloaded version before?

Before the store listing, ManyPI offered a zip to load in Developer mode. That
build no longer updates, so switch to the store version:

1. Send any contacts you want to keep to ManyPI. The two versions don't share
   contacts in the browser.
2. Install the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/manypi-email-finder-lead/picghbcemlfoofheelmfghbmflpnclja) and sign in.
3. Open `chrome://extensions`, remove the old ManyPI card (it shows a folder
   path under **Load unpacked**), and delete the unzipped folder.

## Use an API key instead

In the extension's settings, open **Advanced** and paste a ManyPI API key with
the **Write** permission. Create one under **API Access** in your profile
menu.

## Site access

The first time you scan a site, Chrome asks to let ManyPI read it. You can
allow one site at a time; **Find companies** asks once for all sites, because
it scans sites you pick from a list.

## Sign out

**Settings → Sign out** forgets the sign-in on this browser. Your scanned
contacts stay in the browser until you clear them. To revoke the connection
itself, disconnect it in **Apps & integrations** in ManyPI.

## If something doesn't work

<AccordionGroup>
  <Accordion title="Add to Chrome is greyed out or blocked">
    Your organization manages this Chrome and limits which extensions can be
    installed. Ask your IT team to allow **ManyPI: Email Finder & Lead Extractor**.
  </Accordion>
  <Accordion title="Two ManyPI icons in the toolbar">
    You still have the downloaded version. Remove it as described in
    [Installed the downloaded version before?](#installed-the-downloaded-version-before)
  </Accordion>
</AccordionGroup>

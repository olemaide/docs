## Connect

<Steps>
  <Step title="Create an API key">
    In Close, open **Settings → Developer → API Keys** (or go straight to
    [API keys](https://app.close.com/settings/developer/api-keys/)) and click
    **New API Key**. Copy it.
  </Step>
  <Step title="Paste it in ManyPI">
    Open **Integrations** in the sidebar, click **Close**, paste the key, and
    click **Connect**.
  </Step>
</Steps>

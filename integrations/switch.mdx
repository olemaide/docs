Paste your current tool's API key and ManyPI brings over what you have built
there. It scans first, so you see what it found before anything is imported.

## What comes over

| | |
| --- | --- |
| **Leads** | With their custom variables, merged into any you already have. |
| **Campaigns** | Recreated as drafts with their email steps and variants. |
| **Where you left off** | Leads the old tool had not emailed yet are queued in the new campaign. |
| **Do-not-contact** | Block lists, bounces and unsubscribes, so nobody who opted out hears from you again. |

Nothing sends until you connect an inbox and launch. The key is stored
encrypted and erased when the import ends, and the import keeps going if you
close the tab.

## Another tool

For a tool not listed, export its leads and drop the file anywhere on
**Leads**. ManyPI matches the columns the way it does for any CSV or Excel
file.

| Tool | Where the export is |
| --- | --- |
| Reply.io | **People**, select all, then **Export to CSV** |
| Woodpecker | **Prospects**, select all, then **Export** |
| Mailshake | **Recipients** in the campaign, then **Export to CSV** |
| Outreach | **Prospects**, select all, then **Export to CSV** |
| Salesloft | **People**, select all, then **Export** |
| Hunter | **Leads**, choose the list, then **Export to CSV** |

Do-not-contact lists exported the same way can be added to your
[suppression list](/outreach/replies#suppression-list).

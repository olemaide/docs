Custom connectors need a paid ChatGPT plan with developer mode turned on.

## Sign in with your browser

<Steps>
  <Step title="Turn on developer mode">
    Open **Settings → Connectors → Advanced** and switch on **Developer mode**.
  </Step>
  <Step title="Create the connector">
    Under **Connectors**, click **Create**, name it `ManyPI`, and paste:

    ```
    https://mcp.manypi.com/mcp
    ```

    Choose **OAuth** as the authentication. ChatGPT reads the rest from
    ManyPI, so there is no client ID or key to enter.
  </Step>
  <Step title="Connect">
    ChatGPT opens ManyPI in a new window. Sign in, click **Approve**, and the
    connector goes live. You can revoke it any time under **Connected apps**
    on the MCP page of the ManyPI dashboard.
  </Step>
  <Step title="Use it in a chat">
    Start a new chat, open the **+** menu, choose **Developer mode**, and pick
    **ManyPI**.
  </Step>
</Steps>

<Note>
  No API key is needed in ChatGPT: signing in connects your workspace. API
  keys are for clients that let you set a header, such as
  [Cursor](/mcp/clients/cursor) or [Claude Code](/mcp/clients/claude-code).
</Note>

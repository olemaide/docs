Add to `~/.factory/mcp.json`:

```json
{
  "mcpServers": {
    "manypi": {
      "type": "http",
      "url": "https://mcp.manypi.com/mcp",
      "headers": { "Authorization": "Bearer mpi_your_api_key" }
    }
  }
}
```

Start a new Droid session and run `/mcp` to see ManyPI and its tools.

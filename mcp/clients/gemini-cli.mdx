<Steps>
  <Step title="Edit the settings">
    Add to `~/.gemini/settings.json`:

    ```json
    {
      "mcpServers": {
        "manypi": {
          "httpUrl": "https://mcp.manypi.com/mcp",
          "headers": { "Authorization": "Bearer mpi_your_api_key" }
        }
      }
    }
    ```
  </Step>
  <Step title="Check it">
    Run `gemini`, then `/mcp`. ManyPI is listed with its tools.
  </Step>
</Steps>

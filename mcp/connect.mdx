## Two ways to sign in

- **With your browser (OAuth).** Nothing to paste. Claude Code, Claude.ai and
  Desktop, Cursor and VS Code support it.
- **With an API key.** Works in every client. Create one under **API Access**
  in the profile menu and send it as `Authorization: Bearer mpi_…`.

<Tip>
  Use browser sign-in where you can: there is no key to leak, and you can
  revoke the connection from **Settings → Connected apps** at any time.
</Tip>

An API key needs `read`, plus `agents` to find leads, `write` to draft emails
and create sequences, campaigns and imports, and `outreach:send` to send. See
[API keys and permissions](/platform/api-keys) and
[Authentication](/mcp/authentication).

## Any other client

If your client supports MCP over Streamable HTTP, point it at
`https://mcp.manypi.com/mcp` with an `Authorization: Bearer` header. If it only
starts local processes (stdio), bridge with `mcp-remote` (needs Node.js):

```bash
npx -y mcp-remote https://mcp.manypi.com/mcp \
  --header "Authorization: Bearer mpi_your_api_key"
```

## Troubleshooting

<AccordionGroup>
  <Accordion title="The tool list is empty" icon="circle-question">
    Almost always authentication. Check the header is exactly
    `Authorization: Bearer mpi_…`, and confirm the key works:

    ```bash
    curl https://app.manypi.com/api/user -H "Authorization: Bearer mpi_your_api_key"
    ```
  </Accordion>
  <Accordion title="401 Unauthorized" icon="circle-question">
    The key is missing, revoked or expired, or a browser sign-in has expired
    and the client needs to sign in again. Reconnect from the client's MCP
    panel.
  </Accordion>
  <Accordion title="A tool returns a permission error" icon="circle-question">
    The key exists but lacks that permission. Finding leads needs `agents`,
    drafting and creating things needs `write`, sending needs `outreach:send`.
    See [API keys and permissions](/platform/api-keys).
  </Accordion>
  <Accordion title="Sending tools fail with outreach_locked" icon="circle-question">
    `enroll_leads` and `send_email` need a paid plan. Everything else works on
    the free plan.
  </Accordion>
</AccordionGroup>

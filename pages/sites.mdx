When one page isn't enough, the advanced editor builds a whole website: several
pages, reusable components, a CMS and more than one language.

## Start a site

- **New page → Advanced site**: **Describe your site**, or **Blank site**.
- From a landing page: **⋮ → Advanced editor**.

<Warning>
  Turning a landing page into a site is one way. The site can't go back to the
  simple editor.
</Warning>

## The editor

| Area | What's there |
| --- | --- |
| Toolbar | **Insert**, **Layout** (Frame, Stack, Grid, Section), **Shapes**, **Preview**, **Publish** |
| Left | **Pages** (add, rename, duplicate, set as home, delete, components), **Layers**, **Assets** |
| Right | **Style** for the selection, **Agent** to build and edit for you |
| Breakpoints | Desktop 1200, Tablet 810, Phone 390 |
| View | Free mode, every breakpoint at once, dark interface, full screen |

**Insert** has Layout, Text, Media, Forms, Basics, Effects & shaders, Sections,
Components and Collections.

The agent remembers what your site is about between sessions.

## CMS

Collections (blog posts, team members, jobs) with your own fields. Each item is
**Draft** or **Live**. Item pages live at `/p/<id>/<page>/<item>`.

## Localization

**Add locale**, then **Translate with AI**. Visitors pick a language with
`?lang=`.

## Analytics

Overview and per-page views, from the last 24 hours to 12 months: live
visitors, unique visitors, page views, bounce rate and time on page, broken
down by source, page, country and device.

## Settings

| Section | |
| --- | --- |
| General | Title, language, name, description, a search preview; **Unpublish** |
| Site images | Tab icon, social preview |
| Custom code | Four slots for your own scripts |
| Domain and link | See [Custom domains](/pages/custom-domains) |
| Redirects | Old paths to new ones |
| Per page | SEO, and **Hide from search engines** (noindex and out of the sitemap) |

**Export as code** (Business) downloads the site.

## Going live

A site needs a [website plan](/pages/website-plans). The publish menu shows
the plan, your domain and **Take offline**.
